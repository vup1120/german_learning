# Deutsch-Quest：聽力與口說練習更新

## 學習方式

每個主要德文段落都會自動補上小喇叭，頁面頂部的聽力工具列可以測試聲音、朗讀本頁、停止，以及選擇 0.65×、0.85×、1×、1.15× 的速度。

每張單字／句子卡：

1. 點開卡片查看翻譯，儲存至既有的間隔複習系統。
2. 按「換一個情境」切換三種例句：原創例句、朋友聊天引述、工作／日常引述。
3. 按「聽例句」播放當前情境的德語句子。
4. 按「分步對話練習」，先選情境，再依序：聽開場 → 跟讀 → 自己回答 → 聽追問並再回答 → 回顧。
5. 可使用支援瀏覽器的「語音轉文字」、文字輸入，或「錄下我的聲音」本機錄音，與德語 TTS 示範聲音自行比較。
6. 想要真正即時的追問和語法回饋時，在最後一步按「和 AI 老師說德文」，直接在網站裡用 Gemini Live 語音對話（需先在「AI 設定」貼上 Gemini API key）。分步練習本身是有步驟的情境練習，不是發音精確評分。

所有原有 Friends／電影詞彙中有已編寫例句的卡片都採用原創來源句。生活用語可直接用完整原句進行練習；沒有合適例句的少數詞條，會明確標示「用法詢問」，避免把提問句假裝成自然用法例句。

## 原本小喇叭沒反應：如何排查

舊實作在 SpeechSynthesis 不支援、語音包未安裝或播放出錯時會直接忽略錯誤。新版會顯示播放狀態與錯誤。

1. 打開網站，先按「🔊 測試德語」，調高媒體音量。
2. 如果仍無聲音，檢查瀏覽器是否支援 Web Speech，並確認裝置已安裝德文語音包。不同手機平台支援程度不同。
3. 可嘗試最新版 Chrome、Edge 或 Safari。部分系統可能只有其他語言的聲音。
4. 需要使用語音轉文字時，請在瀏覽器允許麥克風權限；若不支援，可打字。
5. 音訊是瀏覽器德語合成語音，不是電影或影集演員原聲。

## 隱私、限制、檔案

- site/speech.js：統一文字轉語音、速度和錯誤狀態，在使用者點擊時同步開始播音，較長文字會拆段。
- site/app.js：主要德文元素會自動加入小喇叭，詞彙卡另外有例句朗讀和分步口說練習。
- 語音轉文字使用瀏覽器 SpeechRecognition 或 webkitSpeechRecognition；瀏覽器廠商的服務可能需要將語音送往其處理系統。本站沒有另外儲存或傳送辨識資料。
- 自我錄音使用 getUserMedia 和 MediaRecorder，只有使用者主動按錄音才會取得麥克風；錄音只在目前瀏覽器分頁中，沒有上傳至本網站或 GitHub，關閉分頁後不會保存。
- 語音品質與是否支援德語，取決於瀏覽器和作業系統。靜態網站沒有 TTS／LLM 付費 API；無法保證每台設備都能發聲。
- 間隔複習進度仍保存在使用者瀏覽器本機，不會跨裝置同步。
